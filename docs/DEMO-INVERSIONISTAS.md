# Guion de demo para inversionistas — KnowFlow Ventas

> Todo el material de este entorno es sintético y demostrativo: los modelos,
> mecánicas y montos no provienen de una marca ni de una tienda real.

1. Inicia como `experto@knowflow.cl` y abre **Contrastar**.
2. Abre “Plan Canje: retoma del equipo usado”. Muestra el manual, la práctica real
   del piso de venta y las cuatro divergencias con evidencia.
3. Acepta una o más divergencias y selecciona **Generar borrador validable**. El
   resultado queda en borrador, nunca publicado.
4. Inicia como `validador@knowflow.cl` (jefe de tienda), revisa el borrador en
   Bandeja y publícalo.
5. Inicia como `vendedor@knowflow.cl` y pregunta en el Chat *“el cliente dice que
   está muy caro”*: responde con la objeción validada y cita la fuente. Luego
   pregunta *“¿qué cubre el seguro de pantalla?”* para mostrar el guardarraíl: el
   agente **no inventa** y deriva al jefe de tienda.
6. Abre **Mis primeras ventas** y confirma la lectura de un tema crítico.
7. Inicia como `admin@knowflow.cl` y muestra el Dashboard: consultas, la brecha
   *“seguro de pantalla y garantía extendida”* detectada automáticamente y el
   Ciclo de conocimiento. Usa **✨ Redactar borrador con IA** para cerrar el ciclo.

Antes de la reunión: ejecuta `npm run demo:check` con el servidor iniciado, abre
las cuatro cuentas en pestañas privadas y conserva una grabación breve como
respaldo.

No afirmar durante el pitch: multiempresa, WhatsApp, SSO, impacto medido en
conversión/ticket promedio, relación comercial con Samsung u otra marca, ni
resultados provenientes de una tienda real.
